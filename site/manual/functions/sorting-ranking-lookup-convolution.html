    Functions

    Sorting, ranking, lookup, convolution

    convol convolve crosscorr csort deconvolve hlookup lookup match order Rank reverse rsort sort vhlookup vlookup

    convol

    convol(S, K, [BC], [OV])

    Convolution of an array with a kernel, 1D or 2D, with an arbitrary phase.

    Notes
    The same function as convolve, under an older name.

    convolve

    convolve(S, K, [BC], [OV])

    Convolution of an array with a kernel, 1D or 2D, with an arbitrary phase.

    Notes
    Convolution of a signal with a kernel. For two vectors the full result has n + m − 1 elements; for matrices the result has the size of the signal. BC chooses the boundary (0 zero padding, the default; 1 circular; 2 reflect; 3 continue) and OV the initial overlap of the kernel (1 in 1-D, the centred kernel in 2-D by default). Computed directly in the time domain. The operator A ∗ B is the linear convolution and A ⊛ B the circular one.

    crosscorr

    crosscorr(S, K, [BC], [OV])

    Cross-correlation of an array with a kernel, 1D or 2D: the convolution with the kernel reversed, at the same BC and OV.

    Notes
    The cross-correlation: the convolution with the kernel reversed (rotated by 180° for matrices), with the same boundary and overlap options as convolve.

    csort

    csort(A, n)

    Rearranges rows so column n ascends.

    Julia
    Base.sortslices
    Notes
    Rows rearranged so that column n (counted from ORIGIN) ascends; stable. Julia equivalent: sortslices(A, dims=1, by=r -> r[n]).

    deconvolve

    deconvolve(vz, vx)

    1D deconvolution of two vectors: the first n - m + 1 elements of the circular deconvolution.

    Julia
    FFTW.fft
    Notes
    The first n − m + 1 elements of the circular deconvolution of vz (n elements) by vx (m elements), computed with FFTs; an exact quotient comes back as polynomial division gives it, otherwise the minimum-norm circular solution.

    hlookup

    hlookup(z, A, r, [modifier | f])

    Searches the first row of A, returns row r entries.

    Notes
    Searches the first row of A and returns row r of the matching columns, as a column vector.

    lookup

    lookup(z, A, B, [modifier | f])

    Finds z in A, returns entries of B at the same positions as a column-wise vector.

    Notes
    The elements of B at the positions where A matches z (with the modifiers of match), as a column in column-wise order. A and B must have the same size.

    match

    match(z, A, [modifier | f])

    Indices of matching elements, nested array for matrices, column-wise.

    Notes
    The indices of the elements of A equal to z, counted from ORIGIN. For a matrix each match is a vector [row; column], scanned column by column. An optional modifier selects otherwise: "eq", "not", "gt", "lt", "geq", "leq", "near" (closest values) or "range" (the interval of an ascending vector that holds z), or a function f(element, z). No match is an error (so a try can catch it). Julia equivalent: findall, whose indices start at 1.

    order

    order(v)

    Indices (relative to ORIGIN) that sort v.

    Julia
    Base.sortperm
    Notes
    The indices, counted from ORIGIN, that put v in ascending order; stable. Julia's sortperm returns 1-based indices.

    Rank

    Rank(v)

    Rank positions of the elements of v (ties averaged, first rank is 1).

    Notes
    The rank of each element (1 for the smallest); tied elements get the mean of their ranks. Not to be confused with rank, the matrix rank.

    reverse

    reverse(A)

    Reverses vector elements or matrix rows.

    Julia
    Base.reverse
    Notes
    Reverses a vector, or the order of the rows of a matrix (Julia's reverse(A, dims=1)).

    rsort

    rsort(A, n)

    Rearranges columns so row n ascends.

    Julia
    Base.sortslices
    Notes
    Columns rearranged so that row n ascends; stable.

    sort

    sort(v)

    Vector in ascending order (heapsort; unstable; imaginary part ignored).

    Julia
    Base.sort
    Notes
    Ascending by real part; a row or column vector keeps its orientation; a matrix is an error. The imaginary part is ignored.

    vhlookup

    vhlookup(z1, z2, A, [modifier | f])

    Entry at intersection of z1 (first column) and z2 (first row).

    Notes
    The element at the first row whose first entry matches z1 and the first column whose first entry matches z2.

    vlookup

    vlookup(z, A, c, [modifier | f])

    Searches the first column of A, returns column c entries.

    Notes
    Searches the first column of A for z and returns column c (counted from ORIGIN) of the matching rows.
