    Functions

    Strings

    concat format num2str search str2num str2vec strlen substr vec2str

    concat

    concat("S1", "S2", …)

    Joins strings.

    Julia
    Base.string
    Notes
    Joins two or more strings; every argument must be a string (use num2str for numbers). Julia's string or * also converts other values.

    format

    format("Sf", x1, x2, …)

    Template with {0}, {1}, … placeholders.

    Notes
    format("Span {0} m, load {1}", L, q) replaces {0}, {1}, … with the arguments, numbers formatted as by num2str. Placeholders count from 0 regardless of ORIGIN.

    num2str

    num2str(z)

    Scalar to string.

    Julia
    Base.string
    Notes
    The number as text with at most three decimals, trailing zeros dropped; complex numbers as a+bi; quantities with their unit. Julia's string writes the full precision.

    search

    search("S", "SubS", m)

    Start position (counted from ORIGIN) of SubS at or after m, or -1 when absent.

    Julia
    Base.findnext
    Notes
    search(S, T, m): the position of the first T in S at or after position m, counted from ORIGIN, or −1 when it is absent (Julia's findnext returns nothing and a 1-based range).

    str2num

    str2num("Sn")

    String to constant (complex, engineering notation allowed).

    Julia
    Base.tryparse
    Notes
    Reads a real or complex constant: "1.5", "-2e3", "1+2i", "3j". Anything else is an error. Julia's parse(Float64, s) reads real numbers only.

    str2vec

    str2vec("S")

    String to vector of code points.

    Julia
    Base.codepoint
    Notes
    A column vector of the Unicode code points of the characters.

    strlen

    strlen("S")

    Number of characters.

    Julia
    Base.length
    Notes
    The number of characters (Unicode code points), not bytes; Julia's sizeof counts bytes.

    substr

    substr("S", m, n)

    n characters from position m, counted from ORIGIN as array indices.

    Notes
    substr(S, m, n): n characters starting at position m. Positions count from ORIGIN like array indices (0 by default), whereas Julia string indices are 1-based byte indices. A count past the end stops at the end.

    vec2str

    vec2str(v)

    Vector of code points (9, 10, 13, 32..255) to string.

    Julia
    Base.Char
    Notes
    A string from a vector of character codes; only 9, 10, 13 and 32 to 255 are accepted.
