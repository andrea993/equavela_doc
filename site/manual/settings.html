    Settings

    Settings live at three levels: the application (for you, on this computer), the worksheet (saved in the file) and the region.

    Application options

    File › Options:

    • Autosave: whether modified worksheets are backed up automatically, and how often (in seconds). A backup never changes your file; see recovery.
    • Spelling: whether misspelt words in text regions are underlined.

    The layout of the window (ribbon mode, side panel, panel widths, recent files) is remembered for you automatically. Shortcuts work on every keyboard layout: each one is Ctrl with the character shown, typed with the keys that type it on your layout.

    Region settings

    A math region can override the result format and set its own font size, colour and highlight. A text region can have its own spelling language. Any region can be disabled. Plots, images, Julia blocks and result boxes store their size.
