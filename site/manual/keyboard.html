    Keyboard shortcuts

    Equavela has one table of shortcuts for every keyboard layout. A shortcut is a character: Ctrl+[ is Ctrl and the character [, typed with the keys your layout uses for it. On the Italian layout it is Ctrl+AltGr+è, and Ctrl+= is Ctrl+Shift+0. A layout without the character has no shortcut for it: run the command from the ribbon or the Commands palette (Ctrl+K), which shows the shortcuts next to each command. Help › Keyboard shortcuts prints them.
