    Functions

    Array creation, joining and subdividing

    augment diag identity logpts logspace matrix stack submatrix vec

    augment

    augment(A, B, C, …)

    Places arrays side by side, left to right.

    Julia
    Base.hcat
    Notes
    Places arrays side by side; a scalar counts as a 1 × 1 block. All arguments need the same number of rows.

    diag

    diag(v/M)

    Vector to diagonal matrix, or square matrix to its diagonal vector.

    Julia
    LinearAlgebra.diagm, LinearAlgebra.diag
    Notes
    A vector gives the square diagonal matrix (diagm); a square matrix gives the column of its diagonal (diag). Julia's diag also accepts non-square matrices.

    identity

    identity(n)

    n x n identity matrix.

    Julia
    LinearAlgebra.I
    Notes
    An n × n identity matrix of doubles, as Matrix(1.0I, n, n).

    logpts

    logpts(minexp, dec, dnpts)

    dec decades of log-spaced points starting at 10^minexp, dnpts per decade.

    Notes
    dec·dnpts points 10^(minexp + k/dnpts), k = 0, 1, …: whole decades starting at 10minexp, without the start of the next decade.

    logspace

    logspace(min, max, npts)

    npts log-spaced points from min to max (positive reals, compatible units).

    Julia
    Base.range
    Notes
    npts points spaced evenly on a logarithmic scale from min to max, both included; both must be positive and have the same unit, which the points keep. Julia equivalent: exp10.(range(log10(a), log10(b), length=n)).

    matrix

    matrix(m, n, f)

    m x n matrix, element (i, j) = f(i, j), i = 0..m-1 and j = 0..n-1.

    Notes
    matrix(m, n, f) builds an m × n matrix with element (i, j) equal to f(i, j), where i and j count from 0 whatever ORIGIN is. Julia equivalent: [f(i, j) for i in 0:m-1, j in 0:n-1].

    stack

    stack(A, B, C, …)

    Places arrays top to bottom.

    Julia
    Base.vcat
    Notes
    Places arrays top to bottom; a scalar counts as a 1 × 1 block. All arguments need the same number of columns. Elements may be of mixed kinds (numbers, strings, arrays).

    submatrix

    submatrix(A, ir, jr, ic, jc)

    Rows ir..jr and columns ic..jc of A.

    Notes
    submatrix(A, ir, jr, ic, jc) is Julia's A[ir:jr, ic:jc] with indices counted from ORIGIN. Reversed bounds (jr < ir) return the rows or columns in reverse order. The result is always a matrix, also when it is 1 × 1.

    vec

    vec(x, y, z) / vec(x, y) / vec(x)

    Vector from first x, second y (step y-x) to last z.

    Julia
    Base.collect
    Notes
    vec(x, y, z) is the column from x to z with step y − x, vec(x, z) with step 1 (−1 when z < x), and vec(i) turns a range variable into a vector. Unlike Julia's vec, which reshapes an array into a vector, this function builds a vector from a range, as collect(x:step:z).
