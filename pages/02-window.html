The window

From top to bottom the Equavela window holds the title bar, the ribbon, the document tabs, the message bar, the worksheet and the status bar. Panels open beside the worksheet and the Julia REPL opens above the status bar.

Title bar

The title shows the document name. On its left are quick-access buttons: New, Open, Recent, Save, Undo and Redo. Recent lists the last ten worksheets you opened, imported or saved and, under Projects, the recent project folders. Choosing a worksheet that is already open brings its tab to the front.

The ribbon

The ribbon groups commands by task:

TabWhat it holds
FileNew, open, save and close worksheets; new, open, convert, configure, pack and close projects; the Julia environment; extracting portable documents; importing .mcdx worksheets; PDF export, printing and options.
EditUndo, redo, cut, copy, paste, selection, deletion, Find, Replace and spelling.
InsertMath, text, plot, table, image, Julia block, area and include regions; templates for fractions, powers, roots, derivatives, integrals and sums; page setup, page breaks and spacing.
MathOperators, symbols and subscripts; units, constants and labels; the function catalogue, matrix functions and programming; symbolic keywords; line breaks, result formats and the math font.
CalculateCalculate, calculate all, automatic calculation, stop, disabling regions, calculation settings and moving between problems.
ViewPage and draft view, the side panel, the Julia REPL, compact ribbon, zoom and fit.
HelpCommand search, the function catalogue, keyboard shortcuts, function help and this manual.

A contextual tab appears next to them while it is useful and disappears afterwards:

  • Text while you edit a text region: bold, italic, underline, sub- and superscript, size, alignment, paragraph styles and inline math.
  • Matrix while the caret is in a matrix, or a selected region shows a matrix result: insert and delete rows and columns, clear cells, and how many elements a result shows before it scrolls.
  • Plot for the one selected plot: plot type, traces, trace style, axes and grid.
  • Area for a selected area: collapse or expand it.
  • Image for a selected image: original size or replace the picture.

The tooltip of every button shows its keyboard shortcut, with the US keys; any layout types it with the keys of the same characters (see Keyboard shortcuts). View › Compact ribbon hides the labels and lowers the ribbon to give the page more room; a narrow window uses the compact ribbon automatically. On a narrow window the ribbon scrolls sideways: arrows at its edges, or the mouse wheel over it, reach every command.

The command palette

Press Ctrl+K to search every command, operator, symbol, constant, unit, symbolic keyword and built-in function by name or by a related word. Each entry shows its shortcut. Enter runs or inserts the highlighted entry. Every ribbon command is also in the palette.

Insert panels

The Operators, Symbols, Programming, Constants, Units and Symbolics buttons of the Math tab open a panel. The chips at its top are the sections of the list; click one to scroll to it. The search field filters all panels at once, and Enter inserts the first match. Panels can be pinned, moved and closed; clicking an entry never takes the keyboard away from the region you are editing.

Document tabs and the message bar

Each open worksheet, project text file or image has a tab. An asterisk after the name means unsaved changes. Rest the pointer on a tab to see the full path of its file; right-click it for Show in folder, Copy path and Close.

The message bar under the tabs shows one message at a time. Green messages confirm what you asked for and close themselves after a few seconds; blue ones are hints; amber ones say that something was done only in part; red ones report an error.

The side panel

The side panel inspects the worksheet in front. Every row takes you to the region it names.

  • Variables: every name the worksheet defines, with its value, where it is defined and where it is used.
  • Outline: the headings of the text regions, the areas and the regions in reading order.
  • Problems: errors and unit warnings. Calculate › Next problem and Previous problem walk through them on the page.
  • Includes: the worksheets this one includes and the names they provide.

When a project is open, the project explorer shows its folder. Drag the panel's edge to change its width; View › Side panel shows or hides it.

The status bar

From left to right: the page indicator (click it and type a page number to jump there), the calculation mode (AUTO with a green dot, or manual; click to switch), the kernel state, the Find and Replace fields, the REPL button, and on the right the zoom percentage with its slider and the buttons for page view and draft view. Ctrl+mouse wheel zooms around the pointer; Ctrl+0 resets the zoom.

The Julia REPL

The REPL button opens a real Julia terminal in the environment of the open project, or in the shared environment when no project is open. It supports Julia's history, multi-line input, help mode (?), package mode (]) and shell mode (;). The definitions of project worksheets are reachable as Project.<worksheet>.<name>. Restart REPL, in the panel header or the button's context menu, starts the kernel again. See Julia in worksheets.

Context menus

A right click, the Menu key or Shift+F10 opens the context menu of what is under the pointer or selected: cut, copy, paste, delete, disable, region-specific commands and the help for a function.
