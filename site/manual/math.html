    Entering mathematics

    A math region holds one statement: a definition, an evaluation, or both. You type it in a linear way and Equavela draws it in two dimensions as you go: fractions stack, exponents rise, roots grow over their contents.

    Starting a math region

    Click where the region should go and start typing; any character that can begin an expression starts a math region at the crosshair. Ctrl+Shift+M or Insert › Math starts one explicitly. The vertical bar of the crosshair behaves like a text cursor: the first line of the region is placed across it.

    Press Enter to finish the region, or Esc to leave it. Arrow keys at the edge of the expression leave the region too, and the crosshair moves beside it so you can continue typing on the same line.

    Six signs, six meanings

    Operators that mean different things never share a glyph:

    SignMeaningTyped as
    :=Definition: the name takes the value on the right, from this point of the worksheet on.:
    ≡Global definition: the name has the value everywhere in the worksheet, also above.Ctrl+Shift+~
    =Numeric evaluation: shows the value.=
    →Symbolic evaluation: shows the expression transformed symbolically.Ctrl+.
    = (bold)Boolean equality: 1 when both sides are equal, 0 otherwise. Used in conditions and solve blocks.Ctrl+=
    ←Local assignment inside a program.{

    A definition can also show its value: type x:2·π= to define x and display it in the same region.

    Caret and selection

    The caret is a vertical insertion bar; a horizontal line under the current operand, the editing line, shows what the next operator applies to.

    • ← → move through the expression in reading order. In a fraction the caret visits the numerator, then the denominator; in an integral the bounds, the integrand, then the variable; in a matrix the cells row by row.
    • ↑ ↓ move between the lines of a stacked layout, for example from numerator to denominator.
    • Space grows the selection one term at a time in the direction the caret faces; pressing it repeatedly ends with the whole expression selected. Insert flips the caret to the other side of the selection.
    • Shift+← / → extend the selection; Ctrl+← / → jump by word; Home and End go to the start and end.
    • Tab and Shift+Tab move to the next and previous placeholder.
    • A double click selects the name or number under the pointer; a drag selects the smallest expression that holds both ends.

    Typing an operator while something is selected applies it to the selection: select a + b and type ^ to get (a + b)^□. Typing anything else replaces the selection.

    Backspace and Delete remove the character or operator next to the caret. Deleting an operator leaves a placeholder for a new one, so you can change a + b into a − b by deleting + and typing -. Deleting a parenthesis removes both parentheses of the pair.

    Placeholders

    A small square □ marks an operand still to be filled. A region with a placeholder is incomplete: it is saved as it is, but it shows an error until you fill it.

    Names

    • A name may contain letters of any alphabet, digits (not first), underscores, periods, and symbols with no operator meaning such as € or ∀. Names are case sensitive.
    • Literal subscript: press Ctrl+- after the name, type the subscript, and press it again to return to the base line. F_max is one name, drawn Fmax. It differs from the index v[i], which is element i of a vector.
    • Greek letters: type the Latin letter and press Ctrl+G (p gives π, w gives ω). Pressed again, it returns to the Latin letter. The Symbols panel has all Greek letters.
    • Labels: a name is a variable, a function, a unit, a constant, a system variable or a keyword. Equavela resolves most labels from context. Ctrl+U marks the name at the caret as a unit; Ctrl+Q chooses another label. Two names that differ only in their label are different names, so m the variable and m the metre can coexist. Each label has its own style (colour, bold, italic), set in Calculate › Math Formatting.
    • Defining a name with the name of a built-in function or constant hides the built-in from that point on.

    Functions

    Type a function name followed by (, for example sin(. While you type a name, a suggestion list shows matching built-in functions, your own definitions, units and constants; Tab or Enter accepts the highlighted suggestion. A comma adds an argument. F2 opens the function catalogue, where you can search all functions by name, category or description; F1 on a function name opens its help.

    Define your own function with parameters in parentheses: f(x, y) := x² + y². See user functions.

    Long expressions

    A long expression can be broken onto several lines: Shift+Enter inserts a line break at the caret, and Ctrl+Shift+Enter toggles an equation break after the operator at the caret (also Ctrl+Shift++, - and / to type a breaking operator). Line breaks change only the drawing, never the value.

    Copy and paste

    Copied math goes to the clipboard as linear text, such as M := q·L^2/8, which you can paste into another region, another worksheet or a text editor. Pasting linear text into a math region inserts it as mathematics. A selected part of a result can also be copied: the numbers are copied at full precision.
