    Definitions and calculation

    Reading order

    A worksheet is calculated in reading order: from top to bottom and, on the same line, from left to right. A region's place is the top-left corner of its box. A definition x := e is valid from its position on: in the regions to its right on the same line and in every region below. Using x above its definition is the error "x is undefined".

    Moving a region changes what it can see. If a result suddenly says that a name is undefined, check that the definition is still above the region that uses it.

    Redefining a name

    A name can be defined again further down. The new value applies to the regions after the new definition; the regions between the two definitions keep the earlier value. Redefining a built-in function or constant (for example defining your own mean or e) hides the built-in from that point on.

    Global definitions

    A global definition x ≡ e is valid in the whole worksheet, also above its position. The names it uses must be globally defined themselves. A name can have only one global definition, and an ordinary definition of a globally defined name is an error. Global definitions are calculated first, from top to bottom.

    Evaluation

    e = shows the value of e. After the result there is a placeholder for a unit: type a unit there to see the value converted to it (see Units). x := e = defines x and shows its value in one region. A region without any of :=, ≡, = or →, such as a Boolean equality written as a statement, is drawn but not calculated.

    Results are never stored as input: they are recalculated whenever the worksheet is opened.

    User functions

    Define a function by writing its parameters after the name: f(x) := x² + 1, area(b, h) := b·h/2. Call it like a built-in: f(3) = 10. A function sees the definitions above its own definition, not those above the call, so redefining a variable after the function was defined does not change the function. Functions can take vectors, matrices, quantities with units, strings and other functions as arguments, and can return any of them. A function can call itself (recursion).

    A function whose body is a program can use local variables, loops and conditions; see Programs.

    Numeric derivatives: the Differentiation tab

    A numeric derivative (d/dx, ∂/∂x, f′(x), the gradient ∇, Jacob) is computed exactly by automatic differentiation: the derivative is carried through your expression and functions instead of being estimated, so it is as accurate as the value itself. Where an expression does not allow it (a Julia block written for floating-point numbers, some library functions), Equavela estimates the derivative by finite differences instead.

    Click in a region that holds a derivative to open the contextual Differentiation tab and choose the method for that region: Automatic (the default) or Finite differences, with its Tolerance (the relative accuracy of the estimate; empty follows TOL). The choice applies to the derivatives written in the region, also inside a function it defines, wherever that function is used. A symbolic evaluation (→) always differentiates exactly and has no tab.

    Automatic and manual calculation

    In automatic mode (AUTO in the status bar) every change recalculates the regions it affects, and only those: a region that does not depend on the change keeps its result. Moving a region without changing the reading order, editing text, or changing how a result is displayed does not recalculate anything.

    In manual mode results that need updating are marked as out of date. F5 (Calculate) recalculates the out-of-date regions; Ctrl+F5 (Calculate all) recalculates the whole worksheet. Click AUTO in the status bar, or use Calculate › Automatic calculation, to switch.

    While a calculation runs, the region being calculated is marked and the status bar shows the progress. Stop interrupts it. Editing during a calculation stops it and starts again from the change.

    Disabling a region

    Calculate › Disable region turns the calculation of the selected regions off. A disabled region is dimmed, on screen and in print. It has no result, and its definitions are not visible to the regions below, which report the usual "undefined" error. You can still move and edit it; the change counts when you enable it again with the same button.

    Errors

    A region whose calculation fails is drawn with its error: the part of the expression that caused it is marked, and the message says what went wrong. The Problems tab of the side panel lists every error and unit warning; Calculate › Next problem and Previous problem move between them. A region that depends on a failed definition reports that the name is undefined or that its definition failed.

    A unit warning appears before calculation when the dimensions of an expression cannot agree, for example when adding a length to a time. It does not stop the calculation, which then reports the error itself.

    A definition of the same name in the worksheet replaces the constant from that point on.

    Worksheet settings that act like variables

    NameDefaultMeaning
    ORIGIN0The index of the first element of every vector and matrix. Set it in Calculate › Calculation settings; it cannot be defined in the worksheet.
    TOL0.001The convergence tolerance of root finding, numeric integration and differentiation.
    CTOL0.001How closely a solve block must satisfy its constraints.
    PRNPRECISION, PRNCOLWIDTH4, 8Precision and column width of the structured text files written by WRITEPRN.
    CWDthe worksheet's folderThe folder relative file names are read from and written to.

    The calculation settings also hold the random seed, the unit system and how strictly results are checked. Changing a setting recalculates the whole worksheet.
