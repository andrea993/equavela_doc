Julia in worksheets

Every calculation in Equavela runs in Julia. The built-in functions are written in Julia on top of its standard library and well-known packages, and the function reference names the Julia function behind each one. You can also write Julia yourself: in Julia blocks on the page, by calling any Julia package from math, and in the Julia REPL.

Julia blocks

Insert › Julia adds a Julia block at the crosshair. Everything inside it is Julia code, including using and import lines; the header lists the packages it loads. The editor indents automatically, completes names, and colours the syntax; Tab indents and Shift+Tab outdents.

using LinearAlgebra
k_spring = 2.5e3
function stiffness(n)
    K = diagm(0 => fill(2k_spring, n), 1 => fill(-k_spring, n-1), -1 => fill(-k_spring, n-1))
    return K
end
  • A block is enabled or disabled (the switch in its header). An enabled block runs in reading order like a math region, whenever you leave it after a change or something it reads changes. A disabled block never runs.
  • The Run button (▶) or Ctrl+Enter runs the block at once; Shift+Enter runs it and inserts a new block below. The header shows the block's state and how long its last run took; printed output appears under the code.
  • The code may read worksheet variables defined above the block: they are passed in as Julia values before the code runs.
  • Drag the corner handle to give the block a fixed box; Julia: reset to content size returns to the size of the code.

Using Julia names in math

A Julia block exports nothing by itself. Math reaches its names through the qualifier julia.:

  • julia.k_spring is the value of k_spring, and julia.stiffness(4) calls the function. The name after the dot is written exactly as in Julia.
  • Give it a worksheet name with an ordinary definition: K(n) := julia.stiffness registers the function, after which K(4) = calls it; k := julia.k_spring copies the value.
  • julia.Module.f(args) calls a function of a module or package directly, exported or not, once a Julia block has loaded the package, for example julia.LinearAlgebra.nullspace(A).

The name must be defined at the top level of an enabled Julia block above the region (function f, f(x) = …, x = …, const x = …, struct T). A name created inside a begin block or by a macro can be listed in the block's define field.

Coming back, Bool becomes 1 or 0, every real number becomes a double, a Vector becomes a column, tuples become columns, a Symbol or a Char becomes a string. Arrays with more than two dimensions, nothing and missing are errors. Any other Julia object comes back as a handle: the worksheet shows its type and a summary, and you can pass it on to other Julia functions.

Indices. Julia counts from 1. An index returned by a Julia function stays 1-based, and ORIGIN does not apply inside Julia code, while worksheet indices count from ORIGIN (0 by default). Convert when you mix them.

Packages and environments

Packages are installed in a Julia environment, a folder with a Project.toml and a Manifest.toml:

  • a worksheet of a project uses the project's environment;
  • a standalone worksheet can name its own environment folder;
  • every other worksheet uses the shared environment DefaultEnv in your user data folder.

The status bar shows the environment of the worksheet in front; click it, or use File › Julia environment, to open the manager. It lists the packages with their versions and compatibility ranges and can Add package…, Remove, Instantiate, Resolve and Update. Every change is preceded by a snapshot, so a failed or unwanted change can be undone with Undo last change. Restart kernel starts the environment's Julia process again. Each environment runs in its own Julia process, so worksheets in different environments never affect each other.

A region that needs a package that is not installed fails with a clear message. Its entry in the Problems panel offers Add the package to the environment. Nothing is ever installed without your consent.

Trusting a worksheet

Julia code can do anything your user account can do, so a worksheet file you have not opened before is untrusted: its Julia blocks are drawn disabled and regions that call Julia are not evaluated, while ordinary mathematics calculates normally. The first time you run a block, Equavela asks Trust this worksheet?. Trusted worksheets are remembered by path for your user account. Worksheets you create are trusted. Stop trusting this worksheet in the command palette revokes it.

The REPL

The REPL button in the status bar opens Julia's own interactive prompt in the environment of the open project, or in the shared environment. Help mode (?), package mode (]) and shell mode (;) work as usual. The runtime of Equavela is loaded, and the definitions of project worksheets are reachable as Project.<worksheet>.<name>. See project Julia modules.
