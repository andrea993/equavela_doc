    Array characteristics and linear algebra

    cols cond1 cond2 conde condi eigenvals eigenvec eigenvecs geninv genvals genvecs Jacob kronecker last length lsolve max min norm1 norm2 norme normi rank rows rref tr vsum

    cols

    cols(A)

    Number of columns.

    Julia
    Base.size
    Notes
    size(A, 2); 0 when the argument is not an array.

    cond1

    cond1(M)

    Condition number, L1 norm (square M).

    Julia
    LinearAlgebra.cond
    Notes
    ‖M‖₁·‖M⁻¹‖₁ with operator norms, as cond(M, 1); Inf for a singular matrix.

    cond2

    cond2(M)

    Condition number, L2 norm.

    Julia
    LinearAlgebra.cond
    Notes
    The ratio of the largest to the smallest singular value, as cond(M).

    conde

    conde(M)

    Condition number, Euclidean norm.

    Julia
    LinearAlgebra.norm
    Notes
    norm(M)·norm(inv(M)) with the Frobenius norm. Julia's cond has no Frobenius variant.

    condi

    condi(M)

    Condition number, infinity norm.

    Julia
    LinearAlgebra.cond
    Notes
    As cond(M, Inf).

    eigenvals

    eigenvals(M)

    Eigenvalues as a column vector in Julia's order: ascending for a symmetric or Hermitian matrix, otherwise by real part then imaginary part.

    Julia
    LinearAlgebra.eigvals
    Notes
    The eigenvalues as a column vector, in Julia's order: ascending and real for a symmetric or Hermitian matrix (computed with Hermitian), otherwise sorted by real part, then imaginary part. A complex result whose imaginary parts are all zero is returned as real.

    eigenvec

    eigenvec(M, z)

    One unit-length eigenvector for eigenvalue z by inverse iteration.

    Notes
    One unit eigenvector for the eigenvalue z, by inverse iteration on M − z·I. z need only be close to an eigenvalue. Julia has no single-eigenvector function; take the matching column of eigvecs.

    eigenvecs

    eigenvecs(M, ["L"])

    All normalized eigenvectors as columns, in eigenvals order, with LAPACK's signs.

    Julia
    LinearAlgebra.eigvecs
    Notes
    The normalised eigenvectors as columns, in the order of eigenvals, with the signs LAPACK chooses. eigenvecs(M, "L") returns left eigenvectors, which Julia does not compute directly (they are the right eigenvectors of the adjoint, paired by eigenvalue).

    geninv

    geninv(A)

    Generalized (pseudo) inverse, least-squares left inverse.

    Julia
    LinearAlgebra.pinv
    Notes
    The Moore–Penrose pseudo-inverse; for a matrix of full column rank it is the least-squares left inverse.

    genvals

    genvals(M, N)

    Generalized eigenvalues of M*x = v*N*x in Julia's order, by real part then imaginary part.

    Julia
    LinearAlgebra.eigvals
    Notes
    The generalised eigenvalues of M·x = λ·N·x, as eigvals(M, N), in Julia's order.

    genvecs

    genvecs(M, N, ["L"])

    Generalized eigenvectors as unit columns, in genvals order.

    Julia
    LinearAlgebra.eigvecs
    Notes
    The generalised eigenvectors, normalised to length 1, in the order of genvals. "L" as third argument returns left eigenvectors.

    Jacob

    Jacob(F(x), x, [k])

    Jacobian of column vector F with respect to column vector x.

    Notes
    The Jacobian matrix of a column-vector expression F(x) with respect to the column vector x, by numeric differentiation (Richardson extrapolation of central differences, the method of derivative). The optional k uses only the first k variables.

    kronecker

    kronecker(M, N)

    Kronecker product of M and N (numeric evaluation needs square matrices).

    Julia
    LinearAlgebra.kron
    Notes
    The Kronecker product.

    last

    last(v)

    Index of the last element of v (depends on ORIGIN).

    Notes
    The index of the last element of a vector: length(v) − 1 + ORIGIN. Julia's lastindex is always the length because Julia counts from 1.

    length

    length(v)

    Number of elements of column vector v.

    Julia
    Base.length
    Notes
    The number of elements of a column vector. A matrix or a row vector is an error (Julia's length counts every element).

    lsolve

    lsolve(M, v)

    Solves M*x = v by LU.

    Julia
    LinearAlgebra.\
    Notes
    Solves M·x = v: with LU decomposition for a square non-singular matrix (Julia's M \ v), and with the pseudo-inverse (least squares) for a non-square matrix. A singular square matrix is an error. v may have several columns.

    max

    max(A, B, C, …)

    Largest value over arrays, scalars or strings.

    Julia
    Base.maximum
    Notes
    The largest element over all arguments, scalars and arrays together. Strings are compared alphabetically. For complex values it returns the largest real part plus i times the largest imaginary part, which Julia does not define. Units must agree.

    min

    min(A, B, C, …)

    Smallest value over the arguments.

    Julia
    Base.minimum
    Notes
    As max, the smallest.

    norm1

    norm1(M)

    L1 norm: maximum absolute column sum (square M).

    Julia
    LinearAlgebra.opnorm
    Notes
    opnorm(M, 1): the largest absolute column sum. Note that Julia's norm(M, 1) is the sum of all absolute values, a different number.

    norm2

    norm2(M)

    L2 norm: largest singular value of a square matrix M.

    Julia
    LinearAlgebra.opnorm
    Notes
    opnorm(M, 2): the largest singular value.

    norme

    norme(M)

    Euclidean (Frobenius) norm.

    Julia
    LinearAlgebra.norm
    Notes
    norm(M): the Frobenius (Euclidean) norm.

    normi

    normi(M)

    Infinity norm: maximum absolute row sum.

    Julia
    LinearAlgebra.opnorm
    Notes
    opnorm(M, Inf): the largest absolute row sum.

    rank

    rank(A)

    Number of linearly independent columns.

    Julia
    LinearAlgebra.rank
    Notes
    The numerical rank from the singular values, with Julia's default tolerance. The matrix must be numeric and without units.

    rows

    rows(A)

    Number of rows.

    Julia
    Base.size
    Notes
    size(A, 1); 0 when the argument is not an array.

    rref

    rref(A)

    Row-reduced echelon form.

    Notes
    The reduced row echelon form, by Gauss–Jordan elimination with partial pivoting; entries below a tolerance proportional to the machine precision count as zero. Julia's standard library has no rref.

    tr

    tr(M)

    Trace (sum of the diagonal) of a square matrix.

    Julia
    LinearAlgebra.tr
    Notes
    The sum of the diagonal of a square matrix; the elements may carry units.

    vsum

    vsum(v)

    Sum of the elements of an array, in reading order (a matrix row by row) and keeping the units.

    Julia
    Base.sum
    Notes
    The sum of all elements, row by row, keeping units; an empty array sums to 0. The same as the operator Σv.
