    Conditional, type tests and errors

    error if IsArray IsFunction IsNaN IsRange IsScalar IsString SIUnitsOf

    error

    error("S")

    Raises S as an error message.

    Julia
    Base.error
    Notes
    Raises an error with the given message, shown on the region; a try in a program catches it.

    if

    if(cond, x, y)

    Returns x if cond is true (nonzero), else y.

    Julia
    Base.ifelse
    Notes
    if(c, a, b) returns a when c is non-zero and b otherwise. Unlike Julia's ifelse, which evaluates both arguments, only the chosen branch is evaluated (like Julia's ternary c ? a : b), so the other branch may contain an expression that would fail.

    IsArray

    IsArray(x)

    1 if x is a vector or matrix.

    Notes
    1 for a vector or matrix. Julia equivalent: x isa AbstractArray.

    IsFunction

    IsFunction(x)

    1 if x is a function.

    Notes
    1 when the argument is a function (a built-in, your own or a Julia function). Julia equivalent: x isa Function.

    IsNaN

    IsNaN(x)

    1 if x is NaN.

    Julia
    Base.isnan
    Notes
    Element by element; 1 when the real or the imaginary part is NaN; 0 for strings and other values that are not numbers (Julia's isnan throws for them).

    IsRange

    IsRange(x)

    1 if x is a range.

    Notes
    1 when the argument is a range variable.

    IsScalar

    IsScalar(x)

    1 if x is a real or complex scalar.

    Notes
    1 for a number or a quantity, real or complex; 0 for arrays, strings and functions. Julia equivalent: x isa Number.

    IsString

    IsString(x)

    1 if x is a string.

    Notes
    1 for a string. Julia equivalent: x isa AbstractString.

    SIUnitsOf

    SIUnitsOf(x)

    Unit of x scaled to SI.

    Julia
    Unitful.upreferred
    Notes
    One unit of the argument's dimension in SI base units: SIUnitsOf(3 km) = 1 m; 1 for a dimensionless number. Divide by it to strip the unit: x/SIUnitsOf(x). Similar to oneunit(upreferred(x)) in Unitful.
