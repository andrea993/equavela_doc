Solving equations

Equavela solves equations numerically with root, polyroots and solve blocks, and symbolically with the solve keyword (see Symbolic calculation). Differential equations have their own solvers.

One equation: root

root(f(x), x) finds a value of x where f(x) is zero, starting from the current value of x (the guess):

x := 1
root(x³ − 2·x − 5, x) = 2.095

root(f(x), x, a, b) searches the interval [a, b] instead, where f must change sign. The result is accurate to the worksheet tolerance TOL. Units are allowed: the guess or the bounds give the unit of the result.

Polynomials: polyroots

polyroots(v) returns all roots, real and complex, of the polynomial whose coefficients are in v, constant term first: polyroots([−6; 1; 1]) gives the roots of x² + x − 6, 2 and −3.

Solve blocks

A solve block solves a system of equations and inequalities. It is written with ordinary math regions, in reading order:

x := 1                     guess values, defined above
y := 1
Given                      opens the block
x² + y² = 25               constraints, with the bold equal sign or a comparison
y = x + 1
x > 0
s := find(x, y)            the first call of find, minerr, minimize or maximize closes it
s = [3; 4]
  • Type Given in a new math region to open a block; it is drawn as a keyword.
  • Every bare comparison between Given and the closing call is a constraint: Boolean equality (Ctrl+=), <, >, ≤, ≥ or ≠. Both sides must have the same dimension; matrices are compared element by element.
  • Every unknown needs a guess value, normally a definition above Given. The guesses are not changed: define the result (s := find(x, y)) to keep it.
  • With one unknown the result is its value; with several it is a column vector in the order of the call. Each unknown keeps the unit of its guess.
  • A block can be followed by another Given; constraints are never shared between blocks.
  • f(a) := find(x) makes a parameterised block: the constraints may use a, and every call of f solves again.
Closing callWhat it does
find(x, y, …)Values that satisfy every constraint within CTOL; an error when no such values are found.
minerr(x, y, …)The best approximation even when the constraints cannot all be met. Check the result yourself.
minimize(f, x, …), maximize(f, x, …)The values that make the function f (named without arguments) smallest or largest, subject to the constraints. A block may have no constraints.
find(x, y) →Solves the equations of the block symbolically; no guesses are needed.
odesolve(y(t), b)Solves a differential equation; see below.

find and minerr use the Levenberg–Marquardt method on the equation residuals and inequality violations; minimize and maximize a penalty method with BFGS steps. Results depend on the guesses: a guess on the wrong side of an inequality can lead to another root. Given, find and the other closing functions may be written in any letter case.

Differential equations in a solve block

odesolve solves an ordinary differential equation, or a system, written as it appears on paper. The equations use the bold equal sign and primes (Ctrl+') or derivatives:

Given
y′′(t) + y(t) = 0
y(0) = 0
y′(0) = 1
y := odesolve(y(t), 10)
y(1.5) = 0.997

A constraint that uses the variable t is an equation; one that does not is a condition. The result is a function, valid between the first condition point and the end point b; for a system, odesolve([x(t); y(t)], b) returns a column of functions. Conditions at both ends (boundary values) are solved by shooting. The optional third argument is the number of steps (1000 by default).

Differential equation functions

For first-order systems written as a function D(x, y) that returns the derivatives, use the table solvers: rkfixed (fourth-order Runge–Kutta, fixed step), Rkadapt, Bulstoer, Adams, BDF, Radau, Stiffb, Stiffr and AdamsBDF. They return a matrix whose first column holds the points and the other columns the solution. Boundary value problems use sbval and bvalfit, partial differential equations numol, relax and multigrid. See Differential equations.

Tolerances

TOL (default 0.001) controls root, numeric integrals and derivatives; CTOL (default 0.001) controls how closely a solve block must meet its constraints. Change them in Calculate › Calculation settings.
