    Result format

    How a result is displayed never changes the value that other regions use: the full double precision value is always kept.

    Number format

    Calculate › Results › Result format… sets the format of the selected region; Worksheet format… sets the default of the whole worksheet. A region uses the worksheet default for every option it does not set itself.

    OptionChoicesDefault
    FormatGeneral (exponential notation only for very large or small numbers), Decimal (never exponential), Scientific (always), Engineering (exponent a multiple of 3), PercentGeneral
    Precision0 to 15 digits after the decimal point3
    Trailing zerosShow them up to the precision (0.500) or hide them (0.5)hidden
    RadixDecimal, binary, octal, hexadecimal (whole numbers only)decimal
    Complex formCartesian (3 + 4i) or polar (5∠53.13°)Cartesian
    Exponential thresholdIn General format, numbers whose power of ten is at least this (or at most its negative) use exponential notation3
    Zero thresholdNumbers smaller in magnitude than 10−n are shown as 015
    Complex thresholdThe smaller part of a complex number is hidden when it is below 10−n of the larger10
    Nested arraysShow the elements of a matrix inside a matrix, or only its sizecollapsed

    Strings are shown in double quotes.

    Matrix results

    A matrix or vector result is drawn as a matrix in brackets. When it has more elements than Elements to see before scrolling (in the Matrix tab, 12 × 12 by default), it is drawn in a box that scrolls; drag the box's corner handle to make it larger or smaller, and the printed page shows exactly what the box shows. Very large results load the visible part only, as you scroll.

    Matrix › Show indices draws the row and column indices next to a result. You can select cells of a result with the mouse and copy them (Ctrl+C): they are copied as a matrix at full precision.

    Math font and label styles

    Calculate › Math Formatting sets the size (8 to 72 pt, 11 pt by default), the colour and the highlight of the selected math regions. Calculate › Math Formatting › Label styles sets how each kind of name is drawn throughout the worksheet: bold, italic, underline and colour for variables, constants, functions, units, system variables and keywords. These are display settings only.
