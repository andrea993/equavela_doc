    Functions

    Equavela has 431 built-in functions. Each entry gives the call, what it returns, the Julia function or package that computes it and, where Equavela differs from that Julia function, how. Built-in names are case sensitive. Functions of any Julia package can also be called directly; see Julia in worksheets.
