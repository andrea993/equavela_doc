    Hyperbolic and inverse hyperbolic

    acosh acoth acsch asech asinh atanh cosh coth csch sech sinh tanh

    acosh

    acosh(z)

    Inverse hyperbolic cosine.

    Julia
    Base.acosh
    Notes
    For a real argument below 1 the result is complex, where Julia's real method throws. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    acoth

    acoth(z)

    Inverse hyperbolic cotangent.

    Julia
    Base.acoth
    Notes
    atanh(1/z), complex where needed. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    acsch

    acsch(z)

    Julia
    Base.acsch
    Notes
