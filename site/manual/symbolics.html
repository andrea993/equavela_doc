    Symbolic calculation

    The symbolic arrow → transforms an expression exactly instead of computing a number: (x + 1)² → gives x² + 2·x + 1 with the keyword expand, d/dx x²·sin(x) → gives x²·cos(x) + 2·x·sin(x). The symbolic engine is SymPy, the computer algebra library for Python, which Equavela ships with.

    The symbolic arrow

    Type an expression and press Ctrl+.. Without a keyword, the expression is evaluated with the engine's automatic simplifications: derivatives, integrals, sums and limits are carried out, numbers are combined, x + x becomes 2·x. Whole numbers and fractions stay exact (1/3), decimal numbers stay decimal (0.5·x).

    Definitions made above are substituted: if a := 3 is defined, a·x → gives 3·x. Your functions are expanded into their bodies. A name with no definition stays a symbol. The variables of derivatives, integrals, sums and limits are always symbols, even when a variable of the same name is defined.

    Keywords

    Keywords go between the expression and the arrow and say what to do. Insert them from the Symbolics panel or type them in the keyword placeholder; Shift+Enter adds another keyword line. Several keywords apply in order, each to the result of the previous one.

    KeywordArgumentsResult
    simplifyThe simplest form the engine finds.
    expandProducts and powers multiplied out.
    factorFactored into irreducible factors.
    solvex, or x, y, … (optional)The solutions of e = 0 or of the equation e (written with the bold equal sign). One solution is a scalar, several a column. A column of equations with several unknowns is a system: one row per solution, one column per unknown.
    substituteexpression = value (bold)Replaces the expression, including some equivalent factored or expanded forms.
    seriesx = a or x, and the order n (optional)The Taylor series about a (0 by default) with the terms of order below n (6 by default), in rising powers.
    collectxTerms grouped by powers of x.
    coeffsxThe polynomial's coefficients in x, constant term first.
    parfracx (optional)Partial fraction decomposition.
    floatdigits (optional)A decimal number with 15 significant digits, or the number given.
    assumex > 0, x ≥ 0, x < 0, x ≤ 0, x = real, x = integer, complex, even, odd, RealRange(a, b)Assumptions about a symbol for the whole evaluation; for example √(x²) becomes x when x > 0.
    laplace, invlaplacethe variable (optional), the result variable (optional)Unilateral Laplace transform F(s) = ∫₀^∞ f(t)·e^(−s·t) dt and its inverse (for t > 0).
    fourier, invfourieras aboveF(ω) = ∫ f(t)·e^(−i·ω·t) dt over the whole line, and f(t) = 1/(2π)·∫ F(ω)·e^(i·ω·t) dω.
    ztrans, invztransas aboveUnilateral Z transform F(z) = Σ f(n)·z^(−n) and the inverse of a rational causal transform.
    rewritesin, cos, tan, exp, ln, sincos, sinhcos, gamma, fact, …The expression rewritten in terms of that function.
    combineparts, power, exp, ln, sincos, gamma (optional)Terms combined: over a common denominator, powers, exponentials, logarithms, products of sines and cosines into sums, factorials.
    confracn, x (optional)A continued fraction.
    rectangularThe form a + b·i, every variable taken as real: e^(i·x) becomes cos(x) + i·sin(x).

    For example, substitute, X² + R² = Z² changes 2·X² + 2·R² into 2·Z²; use the bold equality sign in the rule. The relation can also be written Z² = X² + R²: when the sum occurs, it is replaced by Z²; otherwise ordinary left-to-right substitution applies. Several rules are applied in the order written, so ω·L = X followed by X² + R² = Z² can rewrite expressions containing L²·ω² + R². Names in a rule's left side remain symbolic even if defined above; the names in the sum of a reversed relation do too. Matching is bounded and may leave a difficult expression unchanged; assumptions control radical simplification, so √(Z²) becomes Z only when Z is known nonnegative.

    The transforms use the conventional variable by default (t for laplace and fourier, s for invlaplace, ω for invfourier, n for ztrans, z for invztrans) or the only free variable of the expression. The keywords cauchy, decomp, explicit, standard and using are recognised but not implemented; they report that.

    Defining with a symbolic result

    A definition can take a symbolic result as its value: g(x) := d/dx f(x) → defines g as the derivative, and S(n) := e →[solve, k] as a solution. The defined name can then be used in numeric calculation.

    Fast Symbolic

    While you edit a math region, Math › Fast Symbolic applies one operation to the expression without writing keywords: Simplify, Expand, Factor, Float, Combine, Rectangular, Continued fraction on the whole expression, and Collect, Differentiate, Integrate, Partial fractions, Coefficients, Series, the Laplace, Fourier and Z transforms and their inverses, and Solve for a variable you select. Alt+S opens the list beside the editor; press the underlined letter to run a command: S Simplify, E Expand, F Factor, V Solve, C Collect, D Differentiate, I Integrate, P Partial fractions.

    Two settings in the menu decide what happens: Evaluate in place (off by default) replaces the expression being edited with the result; otherwise the result is inserted as a new region below the source. Worksheet variables (on by default) substitutes the definitions above, leaving the selected variable free.

    Units and limits

    Units are passed to the symbolic engine as plain symbols: 3 m stays 3·m, and no conversion takes place. Matrices are supported (determinant, transpose, inverse), but strings, ranges, programs and Julia calls are not and report so. Symbolic evaluation runs apart from the numeric calculation and never blocks it.
