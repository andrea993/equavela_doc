    Page setup and printing

    What you see in page view is exactly what is printed: positions are in points, the fonts are part of Equavela, and the same drawing is used on screen, on paper and in the PDF.

    Page setup

    Page setup… (Insert tab, or the command palette) sets the paper size (A4, A3, A5, Letter, Legal or a custom size), the orientation and the four margins, in millimetres or points. Applying it is one undo step. Regions that would end up in the new left or top margin move just inside it; nothing else moves.

    Headers, footers and page numbers

    Header and footer… opens the same dialog at its header and footer fields: a left, a centre and a right part for the header and for the footer, each one line of text. The buttons Page number, Date and File insert the fields {page}, {date} and {file}, which are replaced on every page when it is drawn and printed.

    Page breaks

    Insert › Add page break ends the page at the crosshair. A region that would cross the bottom margin moves to the next page; content that grows pushes the regions below it on, page after page.

    Exporting a PDF

    File › Export PDF… writes the worksheet as a PDF with vector text, mathematics, plots and SVG images, and the full resolution of raster images. The crosshair, selections, editing marks, spelling underlines and other screen aids are never printed. Collapsed areas print collapsed; disabled regions print dimmed, as they appear.

    Printing

    Ctrl+P prints the worksheet through the system print dialog, with the same layout as the PDF.
