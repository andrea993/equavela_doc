    Getting started

    This chapter installs Equavela, starts it and walks through a first worksheet.

    Installing

    Equavela runs on Windows and Linux. The installer carries everything it needs: the application, the Julia runtime with the numerical packages, a precompiled system image so that calculations start quickly, and the Python environment that the symbolic engine uses.

    • Windows: run the setup program. It installs for the current user, without administrator rights, adds a Start menu entry and associates .eqv and .eqvz files with Equavela.
    • Linux: install the .deb package (sudo apt install ./equavela_*.deb) or make the AppImage executable and run it. Both register the worksheet file types with the desktop.

    Only one Equavela window runs per user. Opening a worksheet from the file manager while Equavela is running opens it as a new tab in the existing window.

    The first start

    A small window with the Equavela logo appears while the interface loads; then the main window opens with an empty worksheet. The calculation engine (the kernel) starts in the background. The status bar at the bottom shows its state: while it starts you can already type, and results appear as soon as it is ready. The first start after an installation can take longer, because the engine prepares its caches.

    Opening the manual

    Choose Help › Manual to open the offline manual in its own window. The search box finds functions, commands and keyboard shortcuts. When the caret is on a function name, F1 opens its help entry. Choose Open in the manual for the full reference.

    A first worksheet

    The page shows a small blue cross, the crosshair. It marks where the next region goes. Click anywhere on the page to move it, then type.

    1. Type L:6m. The colon becomes the definition sign :=. While the caret is on m, press Ctrl+U: m is now the unit metre and is drawn in the unit style. (Picking m from the suggestion list that appears while you type does the same.) Press Enter to finish the region.
    2. Below it, type q:12kN/m, mark kN and m as units the same way, and press Enter.
    3. Type M:q*L^2, press → to leave the exponent, then /8 and Enter.
    4. Type M=. Equavela shows the bending moment in SI units, 54000 newton metres.
    5. Click the placeholder after the result and type kN·m: the result reads M = 54 kN·m.

    Change the first region to L := 8 m: the result updates immediately. Every region is calculated from the definitions above it and to its left, in reading order.

    Only a name marked as a unit is a unit. A plain m that nothing defines is the error "m is undefined", so a worksheet can use m for a mass and m (the unit) for metres side by side. See Units.

    Saving

    Press Ctrl+S. A worksheet is saved as a .eqv file, a readable text file that works well with version control. Equavela also keeps an automatic backup while you work, so an unexpected exit does not lose your changes (see Files and recovery).
