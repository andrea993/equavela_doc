    Differential equations

    Adams AdamsBDF BDF Bulstoer bvalfit multigrid numol odesolve Radau relax Rkadapt rkfixed sbval statespace Stiffb Stiffr

    Adams

    Adams(init, x1, x2, intvls, D, [tol])

    Adams-Bashforth, nonstiff.

    Notes
    The fourth-order Adams–Bashforth–Moulton predictor-corrector for non-stiff problems, refining the internal steps until two runs agree within tol. The table solvers return a matrix with intvls + 1 rows: the points in the first column, then one column per unknown. D(x, y) receives the unknowns as a column vector and returns their derivatives; init holds the initial values (a scalar for one equation). x2 < x1 integrates backwards. Implemented in Equavela's runtime; Julia users would reach for DifferentialEquations.jl, whose solvers return solution objects rather than tables.

    AdamsBDF

    AdamsBDF(init, x1, x2, intvls, D, [J], [tol])

    Detects stiffness, calls Adams or BDF.

    Notes
    Chooses BDF when the problem looks stiff at the start (the spectral radius of the Jacobian times the output step exceeds 1) and Adams otherwise. The table solvers return a matrix with intvls + 1 rows: the points in the first column, then one column per unknown. D(x, y) receives the unknowns as a column vector and returns their derivatives; init holds the initial values (a scalar for one equation). x2 < x1 integrates backwards. Implemented in Equavela's runtime; Julia users would reach for DifferentialEquations.jl, whose solvers return solution objects rather than tables.

    bvalfit

    bvalfit(v1, v2, x1, x2, xf, D, load1, load2, scoreb)

    Boundary-value problem by shooting to a match point xf.

    Notes
    As sbval, shooting from both ends to the match point xf: the row of values missing at x1 followed by those missing at x2.

    multigrid

    multigrid(M, ncycle)

    Multigrid solver for 2D elliptic PDE on a square.

    Notes
    Solves Poisson's equation ∇²u = M on the unit square with zero boundary by the multigrid method with ncycle V-cycles per level; M must be square with 2k + 1 rows.

    numol

    numol(x_endpts, xpts, t_endpts, tpts, num_pde, num_pae, pde_func, pinit, bc_func)

    Method-of-lines solver for 1D transient PDE systems.

    Notes
    The method of lines for one-dimensional time-dependent partial differential equations: space is discretised on xpts points with fourth-order differences, time integrated with Radau. bc_func gives, per equation, the left and right boundary values and their type ("D" Dirichlet, "N" Neumann). The result has xpts rows and, for each function, tpts columns.

    odesolve

    odesolve(vf, b, [intvls])

    Solve block: the solution function of an ordinary differential equation system with its conditions, up to the end point b.

    Notes
    Used as the closing call of a solve block of differential equations (see Solving equations): the solution as a function of the independent variable, between the first condition point and b. Initial value problems are integrated with an adaptive Adams/BDF scheme; conditions at two points are met by shooting.

    Radau

    Radau(init, x1, x2, intvls, D, [J], [M], [tol])

    Radau5, stiff.

    Notes
    Radau IIA (order 5), for stiff problems and differential-algebraic systems: the optional mass matrix M solves M·y′ = D(x, y). The table solvers return a matrix with intvls + 1 rows: the points in the first column, then one column per unknown. D(x, y) receives the unknowns as a column vector and returns their derivatives; init holds the initial values (a scalar for one equation). x2 < x1 integrates backwards. Implemented in Equavela's runtime; Julia users would reach for DifferentialEquations.jl, whose solvers return solution objects rather than tables.

    relax

    relax(A, B, C, D, E, S, U, rjac)

    Relaxation solver for Poisson/Laplace elliptic PDE.

    Notes
    Solves the five-point finite-difference equation A·u[i+1,j] + B·u[i−1,j] + C·u[i,j+1] + D·u[i,j−1] + E·u[i,j] = S[i,j] (Poisson or Laplace on a grid) by red–black successive over-relaxation with Chebyshev acceleration; U holds the boundary values and the starting guess, rjac the spectral radius of the Jacobi iteration.

    Rkadapt

    Rkadapt(init, x1, x2, intvls, D)

    4th-order Runge-Kutta, adaptive step.

    Notes
    Runge–Kutta with adaptive steps (Dormand–Prince 5(4) pair), reporting at intvls equally spaced points. The internal tolerance is tighter than TOL. The table solvers return a matrix with intvls + 1 rows: the points in the first column, then one column per unknown. D(x, y) receives the unknowns as a column vector and returns their derivatives; init holds the initial values (a scalar for one equation). x2 < x1 integrates backwards. Implemented in Equavela's runtime; Julia users would reach for DifferentialEquations.jl, whose solvers return solution objects rather than tables.

    sbval

    sbval(v1, x1, x2, D, load1, scorei)

    Finds missing initial values by shooting.

    Notes
    For a boundary value problem: the initial values missing at x1, found by shooting (adaptive Runge–Kutta and Levenberg–Marquardt). load1(x1, v1) builds the initial vector from the guesses and score(x2, y) measures the mismatch at the far end.

    statespace

    statespace(init, t1, t2, intvls, A, [B, u])

    Linear first-order ODE system x' = A(t)x + B(t)u(t).

    Notes

The table solvers return a matrix with intvls + 1 rows: the points in the first column, then one column per unknown. D(x, y) receives the unknowns as a column vector and returns their derivatives; init holds the initial values (a scalar for one equation). x2 < x1 integrates backwards.
