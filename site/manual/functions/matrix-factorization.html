    Matrix factorization

    cholesky Cholesky LU qr QR svd svds

    cholesky

    cholesky(M)

    Legacy lowercase spelling of a test worksheet (deprecated, still works).

    Julia
    LinearAlgebra.cholesky
    Notes
    The lower triangular L with M = L·Lᴴ, as cholesky(Hermitian(M)).L. Kept for older worksheets; prefer Cholesky.

    Cholesky

    Cholesky(M, [p, [u]])

    Returns nested [P; L] (pivoted, lower by default).

    Julia
    LinearAlgebra.cholesky
    Notes
    A nested vector [P; L]: by default with pivoting (RowMaximum), so that P·M·Pᵀ = L·Lᴴ. Cholesky(M, 0) turns pivoting off (P is the identity); a non-zero third argument returns the upper factor Lᴴ. Extract the parts with an index: Cholesky(M)[1].

    LU

    LU(M)

    Returns nested [P; L; U] with P*M = L*U.

    Julia
    LinearAlgebra.lu
    Notes
    A nested vector [P; L; U] with P·M = L·U (partial pivoting). Julia returns a factorisation object with a permutation vector instead of the matrix P.

    qr

    qr(M)

    Legacy lowercase spelling of QR (deprecated).

    Julia
    LinearAlgebra.qr
    Notes
    The matrix augment(Q, R) with the full m × m orthogonal Q and the m × n upper triangular R from Julia's Householder QR. Kept for older worksheets; prefer QR.

    QR

    QR(M, [p])

    Returns nested [P; Q; R] with M*P = Q*R.

    Julia
    LinearAlgebra.qr
    Notes
    A nested vector [P; Q; R] with M·P = Q·R, columns pivoted by decreasing norm (ColumnNorm); QR(M, 0) returns [Q; R] with M = Q·R. Q is the full square factor. Signs are LAPACK's.

    svd

    svd(A)

    Returns nested [U; S; V] with A = U*diag(S)*V^T, as Julia's `svd`.

    Julia
    LinearAlgebra.svd
    Notes
    A nested vector [U; S; V] with the thin factors in Julia's order, A = U·diag(S)·Vᵀ. Unpack it with [U; S; V] := svd(A); [U; S; Wᵀ] := svd(A) defines W as Vᵀ.

    svds

    svds(A)

    Singular values (sqrt of eigenvalues of A^H*A).

    Julia
    LinearAlgebra.svdvals
    Notes
    The singular values in descending order, as a column.
