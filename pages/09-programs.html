Programs

A program is a block of statements with a double vertical bar on its left. It can be the right side of any definition, usually of a function, and its value is the value of the last statement that ran.

sign3(x) := ‖ if x > 0
            ‖   "positive"
            ‖ else if x < 0
            ‖   "negative"
            ‖ else
            ‖   "zero"

Writing a program

  • Type ] to turn the expression at the caret into the first line of a program, or to add a line. In a program, Enter adds a line below; Shift+Enter adds one around the current line.
  • Control statements come from the Programming panel or from shortcuts: if }, else Ctrl+Shift+}, else if Ctrl+;, also if Ctrl+Shift+), for Ctrl+Shift+", while Ctrl+], break Ctrl+Shift+{, continue Ctrl+Shift+:, return Ctrl+\, try Ctrl+[. On another keyboard layout, press Ctrl with the keys that type the same character (see the keyboard reference).
  • On any layout you can type the keyword and press Ctrl+J to turn it into the statement: for Ctrl+J.
  • A local assignment x ← e is typed with {.

Each control statement has a header line with grey placeholders (the condition, or the loop variable and its range) and an indented body with its own bar.

Statements

StatementMeaning
x ← eLocal definition: x exists only inside the program, from this line on, including inside nested blocks and after them. Its value is e. A function can be defined locally too: g(t) ← t².
if cRuns its body when c is non-zero.
else if cRuns when every preceding if and else if condition was zero and c is non-zero.
also if cRuns when c is non-zero, whatever the preceding conditions; if it ran, the following else does not.
elseRuns when no preceding branch ran.
for i ∈ rRepeats the body for each value of a range (1..n, counting down when the end is smaller) or each element of a vector. The variable keeps its last value afterwards.
while cRepeats the body while c is non-zero.
break, continueLeave the innermost loop, or go to its next iteration.
return eEnds the program at once with the value e.
try … on errorRuns the on error body only if the try body raises an error.
"text"A string line acts as a comment.

error("message") raises an error with your message, which a surrounding try can catch.

Values and scope

  • A program can read the worksheet definitions above it. A local definition of the same name hides the worksheet value; x ← x + 1 reads the worksheet's x first.
  • Parameters are passed by value: changing a parameter or its elements inside the program never changes the caller's variable.
  • Arrays grow in programs as on the worksheet: y[i, j] ← … creates y if needed.
  • A program can return several results as a vector, which the caller can destructure: [x, n] := solve2(…).
  • An error is reported on the program line where it happened.

The if function

For a short condition the built-in function if(c, a, b) returns a when c is non-zero and b otherwise. Only the chosen branch is evaluated, so the other branch may contain something that would fail.
