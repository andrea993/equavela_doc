    APPENDPRN

    APPENDPRN("file", M)

    Appends numeric rows to PRN, serialized within the kernel process, and returns M.

    Notes
    Appends the rows of M to a structured data file (the columns must match) and returns M. Writes are serialised, so a loop can log results safely. A relative file name is relative to the worksheet's folder (CWD).

    READBIN

    READBIN("file", "type", [[endian], [cols], [skip], [maxrows]])

    Reads binary data.

    Notes
    Reads raw binary data of the given "type" ("byte", "uint16", "int32", "float", "double" …) and byte order (0 little-endian, 1 big-endian) into a matrix with cols columns, skipping skip bytes. Julia equivalent: read! into an array plus ltoh/ntoh. A relative file name is relative to the worksheet's folder (CWD).

    READFILE

    READFILE("file", "type", [colwidths, [rows, [cols, [emptyfill, ["decsymb"]]]]])

    General reader for .xls/.xlsx, delimited/fixed-width text and ODS.

    Julia
    CSV.File, XLSX.readxlsx
    Notes
    A general reader. "type" is "delimited", "fixed" (then colwidths gives the column widths), "Excel" (.xls and .xlsx) or an OpenDocument spreadsheet. rows and cols select a block, emptyfill replaces missing values (NaN by default), decsymb sets the decimal symbol. Numbers become numbers and other cells strings. A relative file name is relative to the worksheet's folder (CWD).

    READODS

    READODS("file", ["range", [emptyfill]])

    Reads the cells of a range of an OpenDocument spreadsheet (.ods) as a matrix.

    Notes
    Reads a range of an OpenDocument spreadsheet (.ods, the LibreOffice Calc format, which Excel also reads and writes) as a matrix. The range is "B2", "A1:C10", "Sheet name!A1:C10" (or with a period) or "'My sheet'!A1:B2"; without one, the used range of the first sheet. Numbers become numbers, text strings; empty cells take emptyfill (NaN by default). Implemented in Equavela's runtime, with no spreadsheet application needed. A relative file name is relative to the worksheet's folder (CWD).

    READPRN

    READPRN("file")

    Reads numeric PRN and the reference application `.MATRIX` files with complex or string data.

    Notes
    Reads a structured data file: whitespace-separated numeric rows, or the block format that WRITEPRN uses for complex, string and nested matrices. A relative file name is relative to the worksheet's folder (CWD).

    WRITEODS

    WRITEODS("file", M, ["sheet"])

    Updates a named sheet in an OpenDocument workbook while preserving other sheets and their existing workbook content.

    Notes
    Writes a matrix into the named sheet of an OpenDocument workbook (the first sheet by default), creating the file if needed and keeping the other sheets and their content. A relative file name is relative to the worksheet's folder (CWD).

    WRITEPRN

    WRITEPRN("file", M, [rows, [cols]])

    Writes numeric PRN, or a the reference application `.MATRIX` file for complex or string data, and returns the selected matrix.

    Notes
    Writes a matrix as structured data: real numbers as rows with PRNCOLWIDTH columns of width and PRNPRECISION significant digits; complex, string or nested matrices in a block format that READPRN reads back. Returns the matrix written. A relative file name is relative to the worksheet's folder (CWD).
