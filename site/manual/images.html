    Images

    Image regions show SVG, PNG and JPEG pictures on the page. They are never calculated.

    Adding an image

    • Insert › Image opens a file dialog; the image is placed at the crosshair.
    • Ctrl+V with a picture on the clipboard pastes it at the crosshair.
    • Drop image files from the file manager onto the page.

    A new image keeps its natural size, scaled down when necessary to fit the printable width. In a standalone worksheet the image is stored inside the worksheet file; in a project it is stored once in the project's assets/images folder and shared by every worksheet that uses it (see Projects).

    Resizing and replacing

    Select an image to show its corner handle. Dragging it resizes the image and keeps its proportions; hold Shift to change them. The Image tab has Original size, which returns to the picture's own size, and Replace…, which swaps the picture and keeps the position.

    SVG safety

    SVG files are cleaned when they are inserted: scripts, external references, embedded web content and animations are removed, and the message bar says how many parts were removed. What remains is drawn as a picture.

    Print and copy

    An SVG image stays vector in the PDF; a PNG or JPEG keeps all its pixels. Copying regions puts them on the clipboard both as Equavela regions and as an SVG and PNG picture, so you can paste a group of regions as a picture into a word processor or a drawing program.
