    Ai

    Ai(z)

    Airy function of the first kind.

    Julia
    SpecialFunctions.airyai
    Notes
    Same values as Julia; complex arguments allowed.

    Ai.sc

    Ai.sc(z)

    Scaled Ai function.

    Julia
    SpecialFunctions.airyaix
    Notes
    Scaled: Ai(z)·e^(⅔·z^(3/2)).

    bei

    bei(m, x)

    Imaginary Kelvin function of order m.

    Julia
    SpecialFunctions.besselj
    Notes
    Computed as imag(besselj(m, x·e^(3πi/4))), with the same conditions as ber.

    ber

    ber(m, x)

    Real Kelvin function of order m.

    Julia
    SpecialFunctions.besselj
    Notes
    Computed as real(besselj(m, x·e^(3πi/4))). The order must be a non-negative integer and x real; Julia has no Kelvin function of its own.

    fhyper

    fhyper(a, b, c, x)

    Gauss hypergeometric 2F1, -1 < x < 1.

    Julia
    HypergeometricFunctions._₂F₁
    Notes
    The Gauss hypergeometric function 2F1(a, b; c; x), for real arguments with −1 < x < 1 only (Julia's function also continues outside). Returns 1 when a, b or x is 0.

    ibeta

    ibeta(a, x, y)

    Incomplete beta function.

    Julia
    SpecialFunctions.beta_inc
    Notes
    ibeta(a, x, y) is the regularised incomplete beta function Ia(x, y), the first value of beta_inc(x, y, a). Note the order: the integration limit comes first. It needs 0 ≤ a ≤ 1 and x, y > 0.

    J0

    J0(z)

    Bessel function of the first kind, order 0.

    Julia
    SpecialFunctions.besselj0
    Notes
    Equals besselj(0, z). The argument must be dimensionless; it may be complex and may be an array (element by element). A negative real argument is passed as a complex number, so the principal value is returned where Julia's real method would throw. An overflow is an error instead of Inf.

    Julia
    SpecialFunctions.besseljx
    Notes
    Scaled: J0(z)·e^(−|Im z|). Type the name with a literal subscript, J0.sc.

    Jac

    Jac(n, a, b, x)

    Jacobi polynomial.

    Notes
    The Jacobi polynomial Pn(a, b)(x) by its three-term recurrence; a, b > −1, n a non-negative integer. Element by element on x. Julia's standard library has no Jacobi polynomial.

    Jn

    Jn(m, z)

    Bessel first kind, order m.

    Julia
    SpecialFunctions.besselj
    Notes
    Jn(m, z) = besselj(m, z); the order m must be real (it need not be an integer). Arrays of orders or arguments are taken element by element.

    js

    js(m, z)

    Spherical Bessel, first kind.

    Julia
    SpecialFunctions.besselj
    Notes
    js(m, z) = √(π/(2z))·besselj(m + ½, z), which equals SpecialFunctions.sphericalbesselj. At z = 0 it returns the limit (1 for order 0, 0 otherwise). For an integer order and a real argument the result is real.

    Γ

    Γ(z) / Γ(a, x)

    Euler gamma function.

    Julia
    SpecialFunctions.gamma
    Notes
    Γ(z) is gamma(z), also for complex z. At a pole (0, −1, …) or on overflow (Γ(172)) the result is an error instead of Julia's Inf or NaN. Γ(a, x) is the upper incomplete gamma function ∫ₓ^∞ t^(a−1)e^(−t) dt, computed as gamma(a, x) in extended precision; it needs a > 0 and x ≥ 0. Type it with G Ctrl+G.

    δ

    δ(m, n)

    Kronecker delta: 1 if m = n, else 0.

    Notes
    Kronecker delta: 1 when m = n, otherwise 0.

    ε

    ε(i, j, k)

    Antisymmetric tensor of rank 3 (indices ORIGIN..ORIGIN+2).

    Notes
    The Levi-Civita symbol of rank 3: +1 for an even permutation of the indices, −1 for an odd one, 0 when two are equal. The indices run from ORIGIN to ORIGIN + 2.

    Φ

    Φ(x)

    Heaviside step: 0 for x < 0, 1 for x > 0, 0.5 at 0.

    Notes
    Heaviside step. Φ(0) = 0.5, where some definitions use 0 or 1.
