    Functions

    Logarithm and exponential

    exp ln ln0 log sqrt

    exp

    exp(z)

    e^z (more robust algorithm than the power operator for extreme exponents).

    Julia
    Base.exp
    Notes
    A result larger than about 10^307 is an error instead of Inf. The argument must be dimensionless. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    ln

    ln(z)

    Natural log, principal branch for complex or negative real z.

    Julia
    Base.log
    Notes
    The natural logarithm. A negative real argument gives the principal complex value (ln(−1) = πi), where Julia's real method throws; ln(0) is an error instead of −Inf. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    ln0

    ln0(z)

    Like ln, but returns -1e307 at z = 0.

    Julia
    Base.log
    Notes
    As ln, but returns −10^307 at 0 instead of an error, which keeps plots and sums of logarithmic data finite.

    log

    log(z, [b])

    Base-b log of z.

    Julia
    Base.log10, Base.log
    Notes
    log(z) is the base-10 logarithm (Julia's log10), not the natural logarithm as Julia's log(z). log(z, b) is the logarithm in base b, computed as ln(z)/ln(b); note that Julia's log(b, z) takes the base first.

    sqrt

    sqrt(x)

    Square root of x (also the operator on the Operators palette).

    Julia
    Base.sqrt
    Notes
    A negative real number gives the complex root (sqrt(−4) = 2i), where Julia's real method throws. Units are kept: sqrt(9 m²) = 3 m. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element. Same as the root operator.
