Equavela manual

Equavela is a workspace for scientific calculation. You write mathematics on a page the way you would on paper: definitions, formulas, results with units, plots, tables and explanatory text, laid out where you want them. Every result recalculates as soon as something it depends on changes, and the page you see on screen is exactly the page you print or export to PDF.

Behind the page runs Julia, a fast language for numerical computing, together with SymPy for symbolic mathematics. You never have to write Julia to use Equavela, but when you want to, you can call any Julia package from a worksheet or write whole Julia blocks next to your mathematics.

What you can do with it

  • Calculate with units. Write L := 6 m and q := 12 kN/m; Equavela checks dimensions and shows q·L²/8 = 54 kN·m.
  • Work with vectors and matrices, ranges, programs with if, for and while, and more than 400 built-in functions for linear algebra, statistics, interpolation, curve fitting, signal processing, special functions and file access.
  • Solve equations and systems (solve blocks, root, find, minimize) and ordinary differential equations.
  • Transform symbolically: simplify, expand, factor, differentiate, integrate, solve, take Laplace and Fourier transforms.
  • Plot functions and data in XY, polar and contour plots that update with the worksheet.
  • Document your work with formatted text, headings, images, collapsible areas, headers and footers, and export it to PDF.
  • Organise larger work in projects: several worksheets, shared images, Julia modules and their own package environment.

How this manual is organised

  • The Guide chapters, in the left column, explain the program from the first worksheet to projects and printing. Read Getting started first.
  • The Reference lists every keyboard shortcut, and every command.
  • Functions documents every built-in function: its arguments, its result, the Julia function or package that computes it and how Equavela differs from that Julia function.

Use the search field at the top, or press /, to find a function, a command or a topic. Inside Equavela, Help › Manual opens this manual and F1 on a function name opens its entry.

Conventions

  • Key combinations are written Ctrl+Shift+D. Shortcuts are written with the US characters; on another layout, press Ctrl with the keys that type the same character (on the Italian layout Ctrl+[ is Ctrl+AltGr+è).
  • Mathematics is shown in the linear form you can also type, for example x := 2·π. In the worksheet it is drawn in two dimensions.
  • Ribbon commands are written as Tab › Group › Command.
