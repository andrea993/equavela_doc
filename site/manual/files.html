    Files and recovery

    Worksheet files

    A worksheet is saved as a .eqv file: a readable UTF-8 text file in YAML, with the mathematics written in the linear form you can also type (M := q·L^2/8). It works well with version control and can be compared line by line. Images are stored inside the file; results are not stored, because they are recalculated when the file opens.

    • Ctrl+N new worksheet, Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close.
    • Several files can be opened at once; each gets its own tab. A file already open is brought to the front.
    • Closing a worksheet with unsaved changes asks whether to save it.
    • A file written by a newer version of Equavela is refused with a message rather than misread. Files written by older versions are upgraded when they are read and saved in the current format.

    Files with the earlier extensions .mm and .mmz still open, include and import; saving keeps their name, and Save as proposes .eqv.

    Portable documents

    A .eqvz file is a ZIP archive that carries a worksheet, or a whole project, together with what it needs elsewhere: images, included worksheets and the description of its Julia environment. Save as with the portable type writes one; opening a .eqvz document opens its worksheet. A project archive is unpacked with File › Extract project from .eqvz….

    Including worksheets

    Insert › Include refers to another worksheet file by a relative path. The definitions of the included worksheet are visible from the include region on, as if its regions were written there; its evaluations are not shown. Included worksheets may include others; a cycle is an error. The included worksheet is calculated with the settings of the including one (ORIGIN, tolerances) and can use the definitions visible above the include. The Includes tab of the side panel lists what each include provides. A missing file is an error on the include region.

    Automatic backup and recovery

    Every 30 seconds Equavela writes a backup of each modified worksheet: for a saved worksheet a hidden file .<name>.recovery next to it, for an untitled one a file in your user data folder. Saving or closing the worksheet deletes the backup.

    If Equavela or the computer stops unexpectedly, opening the file again offers the newer backup, and at start-up untitled backups are offered. A restored worksheet stays marked as modified, so you decide whether to save it. Modified text files of a project are backed up in the same way; Recovered text files… in the command palette lists them. The interval and whether backups are written are set in the options.

    Crash reports

    If Equavela or its calculation engine fails, a report is written to the equavela/crashes folder of your user data (%LOCALAPPDATA% on Windows, ~/.local/share on Linux). Reports stay on your computer; nothing is sent anywhere. Attach them to a bug report if you want the failure investigated.

    Importing .mcdx and .xmcd worksheets

    File › Import .mcdx or .xmcd worksheet… reads a worksheet in the .mcdx format and opens it as a new untitled Equavela worksheet; the original file is only read. Math, text, plots, tables, images, areas, solve blocks, headers, footers, page settings and result formats are converted. What cannot be converted is listed in the import report (Help › Show import report), region by region, and the message bar says whether everything was imported. Saved results in the file are ignored; everything is recalculated.

    The same command reads the older .xmcd format and its compressed form .xmcdz. Math, text, X-Y plots (traces, styles, limits, logarithmic axes, grids, titles and axis labels), images, page breaks, headers, footers and page settings are converted. A unit such as m or kN that the old worksheet uses without defining becomes a unit, except g, which meant the acceleration of gravity there and is the gram in Equavela. A definition indexed by range variables, such as d[k + 1] := d[k]·q or L[i, j] := …, becomes a program that loops over the ranges, so each element can use the ones computed before it, as in the old worksheet. Included worksheets become includes of the same worksheet as .eqv, found next to the imported file even when the original path was on another computer; import each included worksheet too and save it at the path the include names (the import report lists them). Polar and 3D plots, Windows metafile pictures and components are not converted yet and appear in the import report; the regions of an area are imported without the area.
