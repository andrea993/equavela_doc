    Projects

    A project is a folder that groups worksheets, Julia source files, images and other files, together with their own Julia environment. Use one when a piece of work outgrows a single worksheet, when several worksheets share images or Julia code, or when you want to reuse the results of one project in another.

    Creating and opening

    • File › New project… asks for a name and a new folder. Equavela creates the folder with the project file equavela-project.yaml, a first worksheet worksheets/main.eqv and a Julia module in julia/.
    • File › Open project… chooses a project folder. The tabs you had open in that project the last time open again.
    • File › Convert to project… turns the worksheet in front into a project.
    • Recent in the title bar lists the recent projects above the recent worksheets.
    • File › Close project closes its tabs.

    The project explorer

    While a project is open, the explorer on the left shows every folder and file of the project, like the explorer of a code editor:

    • A click opens a worksheet in a worksheet tab, an image in an image tab, and other files as text when their contents are supported. If a file cannot be displayed, the message bar says why; Open with system app can open it in another program.
    • New worksheet…, New Julia file… and New folder… create in the selected folder; Import files… copies files in.
    • Rename with F2, move by dragging, delete with Delete. Deleted files go to a project trash and can be restored. Renaming or moving a worksheet updates the references to it.
    • Copy files with Ctrl+C and paste into a selected folder with Ctrl+V. Use Ctrl+X to move files or folders, or use the context menu. Save modified files first.
    • Ctrl+click and Shift+click select several entries.
    • Unsaved files are marked. Ctrl+S on a text tab saves the file.

    Hidden files are visible and ordinary hidden files are included when the project is packed. Version-control data and symbolic links are not packed. Application metadata is visible but protected from explorer operations; symbolic links are shown without following them.

    Text tabs are a small code editor with find and replace, go to line, comment toggling, indentation, automatic indentation and completion for Julia files.

    Shared images

    An image inserted into a project worksheet is stored once in assets/images/; inserting the same picture again reuses the file. Image resource usage… (in the command palette or Project settings) lists which worksheets use which images, and which images are missing or unused. A worksheet saved outside the project embeds its images again.

    Julia code in a project

    The project has its own Julia environment (the julia/ folder), shared by all its worksheets, the project's Julia blocks and the REPL. Packages you add there are available to the whole project.

    A .jl file of the project can be loaded into every worksheet: open it and check Load in worksheets beside its save button. The file must define one module, for example module Beams … end; its functions are then called from math as julia.Beams.deflection(L, E, I). The project's own package (julia/src/<Name>.jl) is loaded with import.

    In the REPL of a project, worksheet definitions are reachable as Project.<worksheet>.<name>, for example Project.beam.M_max.

    Using another project

    A project can publish definitions and another project can use them under an alias:

    1. In the providing project, right-click a definition region and choose Export. Only exported definitions are public.
    2. In the consuming project, Add project reference… chooses the providing project's folder and an alias, for example Steam.
    3. In the consumer's worksheets, call the exports with the alias: Steam.h(p, T).

    The consumer locks the list of exports it saw; Update takes in changes. A missing project, a removed export or a cycle between projects is reported in the Problems panel. A reference needs to be trusted like a worksheet. The References section of the explorer lists the references.

    Project settings

    Project settings… shows the project's name, its environment and its Julia modules, and opens the image usage report.

    Portable projects

    File › Pack project as .eqvz… writes the whole project, with its environment description and the projects it references, into one portable file to send to someone else. File › Extract project from .eqvz… unpacks it into a new folder. See portable documents.
