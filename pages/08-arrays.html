Vectors, matrices and ranges

Creating matrices

Press Ctrl+M to insert a matrix of a chosen size, or type [ on an empty placeholder. In a matrix:

  • Tab and Shift+Tab move to the next and previous element; Tab on the last element adds a row.
  • Shift+Space adds a column to the right of the current element, Shift+Enter a row below it.
  • The Matrix tab inserts rows above or below and columns left or right, selects and deletes rows and columns, and clears cells. Drag across cells to select a row, a column or a block; typing then replaces all selected cells at once.
  • Backspace on an empty element of a vector removes the element.

Every array is two-dimensional: a vector is a matrix with one column. Elements can be real or complex numbers, quantities with units, strings, or arrays themselves (nested arrays), and one array can mix them.

Indexing

  • v[i] is element i of a vector, M[i, j] element (i, j) of a matrix. Type [ after the name.
  • Indices count from ORIGIN, which is 0 unless you change it in Calculate › Calculation settings. With the default, the first element of v is v[0].
  • M⟨j⟩ is column j (Ctrl+Shift+C), and the row operator (Ctrl+Shift+R) row i.
  • A range selects several: v[2..5] the elements 2 to 5, M⟨0..1⟩ the first two columns, the row operator with a range a block of rows.
  • An index must be a whole number without unit inside the array, otherwise the region shows an error.

Assigning past the end of an array grows it, filling new elements with 0: v[5] := 1 creates v with six elements if it did not exist. Assigning an element of an undefined name creates the array. A matrix of names on the left of a definition assigns every element: [a; b] := [1; 2]. A name with a transpose on the left defines it transposed: Vᵀ := [1, 2, 3] makes V a column, and [U; S; Wᵀ] := svd(A) defines W as the transpose of the third factor.

Arrays are values: B := A copies A, and changing B afterwards never changes A.

Array arithmetic

Functions such as floor, Re or Im apply to every element. exp, ln, sqrt and the trigonometric and hyperbolic functions of a square matrix are matrix functions (exp(M) is the matrix exponential), as in Julia.

Vectorize

Select an expression and press Ctrl+Shift+^: an arrow is drawn over it, and every operator and function under the arrow applies element by element. A·B under the arrow multiplies elements instead of forming the matrix product, |M| takes the absolute value of every element, and a user function written for scalars is applied to every element. All arrays under the arrow must have the same size; scalars are used for every element.

Range variables

i := 0..10 defines a range variable that takes the values 0, 1, …, 10. x := 0, 0.1..1 steps by the difference of the first two values. When the end is smaller than the start the step is −1.

A range variable is not a vector: it makes the expression that uses it run once per value.

  • f(i) = shows a column of results, one per value of i.
  • v[i] := i² fills a vector element by element, and the right side may read earlier elements: F[i] := F[i−1] + F[i−2].
  • ∑[i] e sums over all values of i.
  • Defining a variable as an expression of a range variable (x := i²) is an error; use vec(i) to turn a range into a vector.

Ranges also work with units: h := 0 m, 100 m..1000 m.

Sums and products

Ctrl+Shift+$ inserts ∑ with a lower bound k = a and an upper bound b; Ctrl+Shift+# the product ∏. The terms are added in order, from a up to b, or downwards when b < a; arrays can be summed. The variable of the sum is local to it.

The functions for creating, combining and analysing arrays (augment, stack, submatrix, identity, eigenvals, lsolve …) are in Array creation, Linear algebra and Matrix factorization.
