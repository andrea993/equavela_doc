Tables

An input table defines several column vectors at once from values you type in a grid, as in a spreadsheet. It is edited like a matrix.

Creating a table

Insert › Table creates a table with two columns, a header row, a units row and two value rows; every cell is a placeholder and the caret is in the first header cell.

  • Header row: one name per column, the name the column defines. A plain name, optionally with a literal subscript.
  • Units row: one unit per column, optional. Every name in it is a unit. When no unit is filled in, the row is not shown once you leave the table.
  • Value rows: the values, any math expression.

Use the arrow keys and Tab to move between cells, and the Matrix tab to insert and delete rows and columns or clear cells. Cells and blocks of cells can be copied and pasted as in a matrix.

What a table defines

Each column defines its name as the column vector of its values, multiplied by its unit:

Fδ
kNmm
00
101.2
202.5

defines F := [0; 10; 20] kN and δ := [0; 1.2; 2.5] mm. The definitions are made at the table's place in reading order, column by column. Values may use names defined above the table, not the other columns of the same table. A column with an empty header defines nothing; a column with an empty value cell is incomplete and defines nothing either. A header that is not a name, a repeated name or an unknown unit is shown as an error on its cell.

The columns are ordinary vectors: plot them, interpolate them (linterp(F, δ, 15 kN)) or fit them (line(F, δ)).
