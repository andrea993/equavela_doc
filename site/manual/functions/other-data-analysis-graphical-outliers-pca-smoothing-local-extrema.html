    anova

    anova(D, Y, [k | term])

    Analysis of variance of a replicated design.

    Notes
    The analysis of variance of a replicated design (the columns of Y are the replicates): source, sum of squares, degrees of freedom, mean square, F and p.

    blackman

    blackman(n)

    Blackman window of n points.

    Notes
    The symmetric Blackman window 0.42 − 0.5·cos(2πk/(n−1)) + 0.08·cos(4πk/(n−1)) (DSP.blackman).

    boxbehnken

    boxbehnken(k)

    Box-Behnken design of 3 to 7 factors.

    Notes
    The Box–Behnken response-surface design for 3 to 7 factors, with its blocks and centre runs.

    boxplot

    boxplot(Data)

    Matrix for a box plot, per column.

    Notes
    For each column of Data, the values that draw a box plot: minimum, quartiles, median and maximum.

    boxplotgraph

    boxplotgraph(Data)

    Two-element vector for box-plot drawing in an XY plot.

    Notes
    Two vectors that draw a box plot as XY traces in an ordinary plot.

    doelabel

    doelabel(D, L)

    Factor names and level values for a design matrix.

    Notes
    Replaces the coded levels of a design matrix with real values: L has a row per factor with its name and one value per level.

    effects

    effects(D, Y, [k | term])

    Effects of the factors and interactions at each level.

    Notes
    The effect of each factor at each level (mean response at that level minus the grand mean). A number k adds the interactions up to order k; a string such as "AB" selects one term.

    expsmooth

    expsmooth(v, a)

    Exponential smoothing with weight a.

    Notes
    Exponential smoothing sᵢ = a·vᵢ + (1 − a)·sᵢ₋₁, starting at the first value; 0 ≤ a ≤ 1.

    filterNaN

    filterNaN(M)

    Removes rows containing NaN.

    Notes
    M without the rows that contain NaN. Julia equivalent: M[.!any(isnan, M, dims=2)[:], :].

    foldover

    foldover(D, [factor])

    Design followed by its fold-over block.

    Notes
    The design followed by its fold-over block with every sign reversed, or only the named factor (a string such as "A") reversed.

    fractfact

    fractfact(k, p)

    Two-level fractional factorial 2^(k-p) with the reference application's generators.

    Notes
    The two-level fractional factorial design 2k−p: the first k − p factors in Yates order and p generated factors (named with their generator, for example "D=ABC") from the standard generator table.

    fullfact

    fullfact(k, [levels])

    Full factorial design of k factors.

    Notes
    The full factorial design of k factors with 2 levels (or levels levels), first factor changing fastest (Yates order). A design matrix has a header row ("Run", "Block", then the factor names A, B, …) and one row per run with the coded levels (−1/+1, or 0, 1, 2 for three levels).

    gaussian

    gaussian(n, a)

    Gaussian window of n points.

    Notes
    The Gaussian window exp(−½·(a·k/((n − 1)/2))²) for k from −(n − 1)/2 to (n − 1)/2.

    Grubbs

    Grubbs(v, a)

    Suspected outlier indices, test statistic, distance to critical value.

    Notes
    Grubbs's test for outliers at significance a, applied repeatedly: the indices of the suspected outliers, their test statistics and their distances to the critical value.

    GrubbsClassic

    GrubbsClassic(v, a)

    Most likely single outlier.

    Notes
    The classic single-outlier Grubbs test: the most likely outlier, if any.

    hamming

    hamming(n)

    Hamming window of n points.

    Notes
    The symmetric Hamming window 0.54 − 0.46·cos(2πk/(n − 1)) of n points. Same values as DSP.hamming(n).

    hanning

    hanning(n)

    Hann window of n points.

    Notes
    The symmetric Hann window 0.5 − 0.5·cos(2πk/(n − 1)) of n points (DSP.hanning).

    hist

    hist(intvls, data)

    Histogram frequencies for the intervals.

    Notes
    The number of data values in each interval; intervals include their left end, and the last one both ends. intvls is either a vector of ascending interval boundaries (one fewer result than boundaries) or a number of equal intervals spanning the data. Compare StatsBase.fit(Histogram, data, edges).

    histogram

    histogram(intvls, data)

    Two-column matrix: interval midpoints and frequencies.

    Notes
    A two-column matrix for plotting: the midpoints of the intervals and the frequencies, with the intervals given as for hist.

    ksmooth

    ksmooth(vx, vy, b)

    Gaussian kernel smoothing whose kernel standard deviation is the bandwidth b.

    Notes
    A normalised Gaussian kernel smoother; the standard deviation of the kernel is the bandwidth b, in the units of vx.

    loadings

    loadings(Nipals)

    PCA loadings.

    Notes
    The loading matrix of a Nipals result.

    localmax

    localmax(M1, [w]) / localmax(x, y, M2, [w])

    Local maxima of 2D/3D data.

    Notes
    The positions and values of local maxima: of a matrix of heights (M1), or of Z over the grid x, y; w is the half-width of the neighbourhood examined.

    localmin

    localmin(M1, [w]) / localmin(x, y, M2, [w])

    Local minima of 2D/3D data.

    Notes
    As localmax, for minima.

    LogNormal

    LogNormal(n)

    n draws of the lognormal distribution of parameters 0 and 1.

    Julia
    Distributions.LogNormal
    Notes
    n draws of the lognormal distribution with parameters 0 and 1; for montecarlo.

    markNaN

    markNaN(M, vindex)

    Sets the indexed elements to NaN.

    Notes
    A copy of M with the indexed elements set to NaN.

    matchNaN

    matchNaN(M)

    Indices of NaN entries.

    Notes
    The indices of the NaN elements.

    medsmooth

    medsmooth(v, [n], [m])

    Median smoothing, window n.

    Notes
    A centred running median with an odd window n (3 by default); at the ends of a vector the window shrinks. For a matrix, n × m windows.

    montecarlo

    montecarlo(F, n, Rvals, [Limits], [dist])

    n Monte Carlo samples of F at random arguments.

    Notes
    n samples of the function F at random arguments. Rvals has a row per argument of F: its name, mean and standard deviation; each argument is mean + σ·r with r drawn from dist (Normal by default, or a function of your own). Limits (lower and upper, NaN for none) truncates a variable: a value outside is drawn again.

    movavg

    movavg(v, n)

    Moving average, window n.

    Notes
    The trailing moving average over n values; the first values average over the elements available so far.

    Nipals

    Nipals(DATA, NumPC, maxiter, "scale/noscale", Acc)

    Principal component analysis by NIPALS.

    Notes
    Principal component analysis of the columns of DATA by the NIPALS algorithm, extracting NumPC components with at most maxiter iterations each, on scaled or unscaled data. The result feeds scores, loadings, PCAeigenvals, PCAvariance and Nipals2. Components agree with an eigen-decomposition up to sign.

    Nipals2

    Nipals2(Nipals, numAddPC)

    Additional principal components.

    Notes
    Extends a Nipals result with more components.

    Normal

    Normal(n)

    n draws of the standard normal distribution.

    Julia
    Distributions.Normal
    Notes
    n draws of the standard normal distribution, as a column; intended as the distribution argument of montecarlo.

    pareto

    pareto(Data)

    Matrix for a Pareto plot.

    Notes
    From a two-column matrix of names and positive values: the rows sorted by decreasing value, with a third column holding the cumulative percentage, for a Pareto chart.

    PCAeigenvals

    PCAeigenvals(Nipals)

    PCA eigenvalues.

    Notes
    The eigenvalues of the principal components of a Nipals result.

    PCAvariance

    PCAvariance(Nipals)

    Accumulated percentage of explained variance.

    Notes
    The cumulative percentage of variance explained by the principal components.

    plackettburman

    plackettburman(n)

    Plackett-Burman design of n runs for n-1 factors.

    Notes
    The Plackett–Burman screening design of n runs (a multiple of 4 from 8 to 48) for n − 1 factors.

    qqplot

    qqplot(v1, [v2 OR "distribution"])

    Two-column Q-Q plot data.

    Julia
    Distributions.quantile
    Notes
    The two columns of a quantile–quantile plot: the sorted data against the matching quantiles of a second data set or of a named distribution (the normal distribution by default).

    quickscreen

    quickscreen(D, Y, [k | term])

    Mean response at the - and + level of each term.

    Notes
    For a −1/+1 design: the mean response at the low and the high level of each term and their difference.

    randomize

    randomize(D)

    The runs of a design matrix in a random order.

    Notes
    The runs of a design matrix in a random order; run numbers move with their rows. Uses the shared random generator (see Seed).

    scores

    scores(Nipals)

    PCA scores.

    Notes
    The score matrix of a Nipals result.

    supsmooth

    supsmooth(vx, vy)

    Adaptive nearest-neighbor least-squares smoothing.

    Notes
    Friedman's super smoother: running-line smoothers with spans of 5, 20 and 50 % of the data, choosing the span point by point by cross-validation.

    taguchi

    taguchi(k, levels)

    Taguchi orthogonal array for k factors.

    Notes
    The Taguchi orthogonal array for k factors at the given number of levels (L4, L8, L9, L12, L27 …); other combinations are an error.

    ThreeSigma

    ThreeSigma(v)

    Indices of points with test statistic > 3.

    Notes
    The indices of the points more than three standard deviations from the mean.

    triangular

    triangular(n)

    Triangular window of n points.

    Notes
    The triangular window of n points, rising from 0 to 1 and back to 0.

    trim

    trim(v, vindex)

    Removes entries specified by vindex.

    Notes
    The vector or matrix without the elements (or rows) at the indices vindex, counted from ORIGIN. Julia equivalent: deleteat! on a copy.

    Uniform

    Uniform(n)

    n draws uniform on [-6, 6].

    Julia
    Distributions.Uniform
    Notes
    n draws uniformly distributed on [−6, 6], so that mean + σ·r spans six standard deviations; for montecarlo.

    VSmooth

    VSmooth(v, w)

    Repeated median smoothing.

    Notes
    A repeated running median: for each window width of w, the median smoother is applied until the result stops changing (within TOL).

    Weibull

    Weibull(n)

    n draws of the Weibull distribution of shape 1 and scale 1.

    Julia
    Distributions.Weibull
    Notes
    n draws of the Weibull distribution of shape 1 and scale 1; for montecarlo.
