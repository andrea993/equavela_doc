    Functions

    Trigonometric and inverse trigonometric

    acos acot acsc asec asin atan cos cot csc sec sin sinc tan

    acos

    acos(z)

    Inverse cosine.

    Julia
    Base.acos
    Notes
    As asin: acos(2) = −1.317i. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    acot

    acot(z)

    Inverse cotangent.

    Julia
    Base.acot
    Notes
    atan(1/z), with acot(0) = π/2. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    acsc

    acsc(z)

    Inverse cosecant.

    Julia
    Base.acsc
    Notes
    asin(1/z), complex where the real value does not exist. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    asec

    asec(z)

    Inverse secant.

    Julia
    Base.asec
    Notes
    acos(1/z), complex where the real value does not exist. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    asin

    asin(z)

    Inverse sine (complex result outside [-1, 1]).

    Julia
    Base.asin
    Notes
    For a real argument outside [−1, 1] the result is complex (Julia's value for a complex argument), where Julia's real method throws a DomainError. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    atan

    atan(z)

    Inverse tangent.

    Julia
    Base.atan
    Notes
    One argument only; for the angle of a point use atan2 or angle. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    cos

    cos(z)

    Cosine.

    Julia
    Base.cos
    Notes
    As sin. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    cot

    cot(z)

    Cotangent.

    Julia
    Base.cot
    Notes
    1/tan(z); a zero tangent is an error. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    csc

    csc(z)

    Cosecant.

    Julia
    Base.csc
    Notes
    1/sin(z); a zero sine is the error "can't divide by zero" instead of Inf. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    sec

    sec(z)

    Secant.

    Julia
    Base.sec
    Notes
    1/cos(z); a zero cosine is an error. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    sin

    sin(z)

    Sine, radians.

    Julia
    Base.sin
    Notes
    The argument is in radians; an angle with the unit deg is converted. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.

    sinc

    sinc(z)

    sin(z)/z, 1 at 0.

    Julia
    Base.sin
    Notes
    sin(z)/z with the value 1 at 0. This is the unnormalised sinc; Julia's sinc(x) is sin(πx)/(πx). Element by element on arrays.

    tan

    tan(z)

    Tangent.

    Julia
    Base.tan
    Notes
    As sin. Of a square matrix it is the matrix function (as Julia's method for matrices); of any other array it applies element by element.
