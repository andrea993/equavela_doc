    cnorm

    cnorm(x)

    Cumulative normal distribution with mean 0, variance 1.

    Julia
    Distributions.Normal, Distributions.cdf
    Notes
    The standard normal distribution function, cdf(Normal(), x); the same as pnorm(x, 0, 1).

    dbeta

    dbeta(x, s1, s2)

    Probability density, beta distribution.

    Julia
    Distributions.Beta, Distributions.pdf
    Notes
    pdf(Beta(s1, s2), x). Shape parameters s1, s2 > 0, as Julia's Beta(α, β). All arguments are dimensionless real numbers; x may be an array (element by element).

    dbinom

    dbinom(k, n, q)

    Probability density, binomial distribution.

    Julia
    Distributions.Binomial, Distributions.pdf
    Notes
    pdf(Binomial(n, q), x). n trials with success probability q, evaluated at k successes. For a non-integer argument the probability is 0. All arguments are dimensionless real numbers; x may be an array (element by element).

    dgeom

    dgeom(k, q)

    Probability density, geometric distribution.

    Julia
    Distributions.Geometric, Distributions.pdf
    Notes
    pdf(Geometric(q), x). The number of failures before the first success, probability q·(1 − q)^k for k = 0, 1, …, as Julia's convention. For a non-integer argument the probability is 0. All arguments are dimensionless real numbers; x may be an array (element by element).

For a non-integer argument the probability is 0. All arguments are dimensionless real numbers; x may be an array (element by element).

    Seed

    Seed(x)

    Resets the shared generator to integer x in 1..2147483647 and returns the previously configured seed.

    Julia
    Random.Xoshiro
    Notes
    Resets the shared random generator, a Xoshiro generator owned by the calculation engine, to the seed x (an integer from 1 to 2147483647) and returns the previous seed. Without Seed, the generator is seeded from the clock when the engine starts, so random numbers differ from run to run; call Seed at the top of a worksheet for repeatable results.
